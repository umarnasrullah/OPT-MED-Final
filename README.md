# 🩺 Physician AssistPro – Medical Scribing Website

**A multi-page, responsive marketing website for a medical scribing service for specialised clinics.**

🌐 **Live demo:** https://umarnasrullah.github.io/OPT-MED-Final/

> This is the **latest version** of the site. Earlier iterations: [Optimal-Website](https://github.com/umarnasrullah/Optimal-Website) (v1) and [Optimal-Website-Final](https://github.com/umarnasrullah/Optimal-Website-Final) (v2).

---

## ✨ Highlights

- Hero section with live-style stats cards (time saved, accuracy, compliance)
- Service pages: **Live**, **Virtual** and **Async** scribing
- Specialty pages: **Cardiology**, **Dermatology**, **Orthopedics**
- Pricing, About and HIPAA / compliance pages
- "Book Demo" and "Start Free Trial" calls to action
- Fully responsive layout for desktop, tablet and mobile

## 📁 Structure

```text
OPT-MED-Final/

├── specialties/        # Individual specialty pages

├── about.html
├── compliance.html

```

## 🛠️ Tech Stack

HTML5 · CSS3 · Vanilla JavaScript · GitHub Pages

## 🚀 Run locally

No build step needed. Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/umarnasrullah/OPT-MED-Final.git
cd OPT-MED-Final
```
